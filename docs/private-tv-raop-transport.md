# Private bounded TV RAOP transport controller

`scripts/private_tv_transport.py` is private trial tooling layered on the existing
`tv-raop` admission scope. It does not change target admission, binary pins,
provider flags, pairing, receiver volume, native grouping, or the admission-only
window wizard.

The controller accepts only a validated `tv-raop` inventory from
`scripts/private_trial_scope.py`, checks that exactly its Apple TV player is
registered, and uses MA's supported authenticated API. Supply the short-lived API
token through an inherited environment variable (default `MA_TOKEN`); the script
never writes, logs, or places it in a receipt.

It generates exact local WAV bytes: 44.1 kHz, stereo, 16-bit, 440 Hz for three
seconds at -45 dBFS, followed by one second of digital silence. The receipt carries
the generated byte count and SHA-256. A one-route local HTTP server binds only to
an explicit IPv4 address and ephemeral port. Its advertised IPv4 address is also
explicit. It serves only `/stimulus.wav`; a completed fetch is measured from that
server, not assumed from a successful MA API request. This identifies only a
client fetch, not Music Assistant's requester identity.

The controller makes one `player_queues/play_media` request and always attempts
`players/cmd/stop` in `finally`. Once playback is requested, the fetch wait and
stop request share a five-second monotonic budget. It requires an already armed
`private_dev_lifecycle.py` run and verifies its live lease before dispatch; that
independent watchdog remains the recovery authority if an HTTP operation stalls.

An `OBSERVED` receipt means only that MA accepted the request, the constrained
source was fetched, and the controller requested stop. `INCOMPLETE` is expected
when the fetch was not observed. Neither outcome claims child `connected`, PCM
arrival, RTP, receiver group membership, audible output, or iPhone controls. Those
fields stay null unless independently captured evidence is attached by the parent.
No packet capture is created or synthesized by this tool.

This is controller infrastructure, not receiver acceptance or a deployment recipe.
Run it only from the intended private host after the parent has supplied the
lifecycle run, inventory, explicit bind/advertised addresses, API endpoint, and
short-lived credential. Do not add household identifiers to this repository.
